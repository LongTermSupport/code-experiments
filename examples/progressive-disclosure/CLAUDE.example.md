# Tide Tables

A toy project for recording which instructions a coding agent loads, and when. Everything in
this folder belongs to that example; nothing here applies to any other project.

Context marker: ROOT-CLAUDE-MD

- Tide Tables predicts high and low tides for one harbour from a CSV of past readings.
- The code is Python 3, in `src/`. The readings are in `data/`.
- Heights are in metres, times in UTC.
